# ApplyFlow 求人・面接メッセージ Chrome拡張機能

Green・dodaで本人が閲覧中の求人詳細をApplyFlowへ保存し、企業メッセージの選択範囲から面接日時・候補・変更・取消を確認後に既存応募先へ反映する個人用の非公式拡張機能です。求人一覧の収集、自動巡回、自動応募、Cookie取得、媒体内部API呼び出しは行いません。

## ビルドと導入

1. リポジトリルートで `npm run extension:build` を実行します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で `browser-extension/dist` を選びます。
4. ApplyFlowを起動し、「設定 → ブラウザ拡張機能」でトークンを発行します。
5. 対象の求人詳細ページで拡張機能アイコンを開き、「この求人ページで有効化」を押します。
6. 保存機能を使うときは、拡張機能の詳細設定にApplyFlow URLとトークンを貼り付けます。

ボタンが表示されない場合は、求人詳細ページで拡張機能アイコンを開き、「現在ページへボタンを再挿入」を押してください。ポップアップに媒体権限と対応ページの診断結果が表示されます。

## 企業メッセージから面接日時を登録

1. Greenまたはdodaの企業メッセージ画面を開きます。
2. 日時を含む企業からのメッセージ1件を選択します。パネルを開いた後も媒体画面を操作でき、「現在の選択を取り込む」で選択し直せます。
3. 送信欄と重ならない右下上部の「面接日時を抽出」を押します。
4. OpenAI APIへの送信対象を確認し、同意して抽出します。
5. 抽出した会社名・ポジションと日時を確認します。完全一致した応募先は自動選択され、表記ゆれ候補は既存への統合または新規作成を選択します。
6. 未登録の応募先は、このパネルから会社・応募先・面接日時を一度に登録できます。

返信のためパネルを退避するときは、右上の「−」、「一時的に隠す」、またはEscを押します。入力・抽出結果は保持され、ページ上の「日時抽出を再開」から同じ状態へ戻れます。

確定日時はダッシュボードと応募先へ表示され、候補日時は返信待ちとして表示されます。日時変更は選択した面接の現在日時を置き換え、取消はその面接をダッシュボードから除外します。

ローカルApplyFlowの既定URLは `http://localhost:3000` です。外部環境を指定する場合はHTTPSが必須です。

## データの扱い

- ページを開いただけではApplyFlowへ送信しません。
- 「ApplyFlowに保存」を押した後に、媒体、求人ID、正規化URLで保存済み確認を行います。
- 保存前に会社名、ポジション、勤務地、雇用形態、給与・報酬、メモを編集できます。
- 求人本文、画像、ロゴ、Cookie、媒体アカウントの認証情報は取得・送信しません。
- 企業メッセージは、利用者が選択または貼り付け、同意した本文だけをOpenAI APIへ送信します。
- メッセージ生本文はApplyFlowのDB、Chrome storage、ActivityLogへ保存しません。重複防止にはSHA-256 digestだけを保存します。
- AI結果は自動登録せず、応募先・対象面接・日時を確認してから登録します。
- 会社名・ポジションが完全一致する既存応募先だけを自動統合します。法人格の前後違いなどは確認なしに統合しません。
- トークンはChromeの信頼済み拡張コンテキストに限定したローカルストレージへ保存し、Content Scriptへ渡しません。
- ローカル設定削除後は、ApplyFlow側でもトークンを失効してください。

Green、dodaおよび各運営会社とは無関係の個人開発ツールです。利用者自身が対象媒体の最新の利用条件を確認してください。
